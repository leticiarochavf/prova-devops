## Sobre o projeto:

Esse projeto foi gerado para apresentar um evento academico de forma simples e organizada, deixando todas as infos em um só lugar 

## O que tem na pagina:

Programação, palestrantes, inscrição e informações do evento

## Tecnologias usadas:

Css, HTML, git e github

## Estrutura:

index.html: onde fica o layout da pagina
style.css: onde fica o estilo da pagina
workflow: onde fica as regras de desenvolvimento 
readme: informações gerais do projeto
img/ : imagens utilizadas no projeto
gitgnore: arquivos que não precisam ser salvos pelo git
